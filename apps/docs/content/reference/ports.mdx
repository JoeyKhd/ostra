| Port | Process | Who connects | Setting |
|---|---|---|---|
| `3000` | The panel (`apps/web`) | Browsers | `OSTRA_WEB_PORT` |
| `8787` | Core (`apps/core`) | Runners, box sidecars, and the GitHub, Linear and Jira webhooks | `OSTRA_CORE_PORT` |

The compose file publishes both. A runner opens no port: it connects out to core.

## The panel

Port `3000` serves the panel, the setup checklist and the device-code page runners and `ostra login` send you to. Browsers reach it at `OSTRA_PUBLIC_URL` (`http://localhost:3000` by default). Put it behind your own TLS proxy for anything but a demo.

## Core

Port `8787` serves the runner protocol under `/runner/v1/`, the webhooks, and the tunnel `ostra preview` opens. Runners, and each `docker` box's sidecar, reach it at `OSTRA_CORE_PUBLIC_URL` (`http://localhost:8787` by default), or `--box-server-url` when a box reaches it at another address. Webhooks from GitHub and each tracker connection need it reachable from the internet: `/webhooks/github/<id>`, `/webhooks/linear/<id>` and `/webhooks/jira/<id>`. Without that, ostra polls each tracker connection (`OSTRA_TRACKER_POLL_SECONDS`) and checks GitHub on a schedule (`OSTRA_RECONCILE_MINUTES`): pull request states, comments, reviews and reopens.

With `OSTRA_PREVIEW_DOMAIN` set, core also answers every host under the preview domain, on this same port, with its preview proxy and nothing else. The proxy in front of core routes them here ([The preview domain](/docs/install/preview-domain)).

## Inside a box

The sidecar's key proxy, git proxy and MCP proxy listen inside the box only, on ports chosen at start, for the agent's container. Nothing outside the box reaches them, and no preview does either: a preview reaches only the task's app processes, the ports the agent announced and the services marked as previews, never a port below 1024 or 7101, the sidecar's control port.

## On a member's machine

`ostra preview` listens on `127.0.0.1` only, on the preview's own port when it's free, else the next free one, or the one `--local` names. It connects out to core, as a runner does.

## Postgres

ostra keeps everything in Postgres, at `DATABASE_URL`. The compose file's Postgres isn't published outside its network. In development, `pnpm db:dev` starts an embedded one on `54329` (`OSTRA_DEV_PG_PORT`).
