`ostra` is one program: a runner (`ostra runner`), the sidecar inside each `docker` box, and a member's own `login`, `checkout` and `logout`. This page matches what `ostra --help` prints, and a test holds the two together.

```sh
ostra --help
```

## Commands

| Command | What it does |
|---|---|
| `ostra runner [flags]` | Start a runner: sign in the first time, then take tasks |
| `ostra runner status [flags]` | Show the runner's ID, server, version window and last refusal |
| `ostra login [--server <url>]` | Sign in as yourself, with a code you approve in the browser |
| `ostra checkout <task> [--dir <folder>]` | Put a task's branches in your own clones (ticket key, task ID or URL) |
| `ostra logout` | Sign out, and revoke the CLI session on the server |
| `ostra --version` | Print the CLI's version |

### ostra runner

The first start signs the runner in. A pool runner trades its join token (`--join-token` or `--join-token-file`) for its runner key. A personal runner, started without one, shows a device code to approve in the panel. After that, the runner connects and takes tasks. See [Pools and join tokens](/docs/runners/pools) and [Personal runners](/docs/runners/personal).

```sh
ostra runner --server http://localhost:8787 --executor docker --slots 2
```

### ostra login

Signs the CLI in as you, with a device code you approve in the browser. The CLI session lasts 30 days (`OSTRA_CLI_SESSION_DAYS`), and you can revoke it sooner in your Account. It can read a task's branches for `ostra checkout`, and nothing else.

### ostra checkout

Fetches each of a task's branches into your own clones and checks them out. Name the task by its ticket key, its task ID or its URL. Without `--dir`, it looks for your clones from the current folder.

## Exit codes

| Code | Meaning |
|---|---|
| `0` | Done |
| `1` | Failed |
| `2` | A usage error: an unknown command or flag, or a flag without its value |
| `3` | The server refused this runner for good: revoked, or a key it doesn't know. Restarting won't help; sign it in again with a new identity |

## Runner flags

Each flag is also an environment variable, and a flag wins over its variable. Values are written `--name value` or `--name=value`.

| Flag | Variable | Default | What it does |
|---|---|---|---|
| `--server` | `OSTRA_SERVER_URL` | (required) | The ostra server's core address, such as http://localhost:8787. |
| `--data-dir` | `OSTRA_RUNNER_DATA_DIR` | ~/.ostra/runner | The runner's folder: its key pair, its spool and the task workspaces. |
| `--transport` | `OSTRA_RUNNER_TRANSPORT` | auto | How the runner talks to the server: auto (a WebSocket, falling back to HTTP by itself when a proxy blocks it), websocket or http. Both go through HTTPS_PROXY, HTTP_PROXY and NO_PROXY, and trust NODE_EXTRA_CA_CERTS. |
| `--executor` | `OSTRA_RUNNER_EXECUTOR` | host | Where tasks run: host (a worktree on this machine, not isolated), docker (a box per task) or kubernetes (a pod per task, from a pool runner in the cluster). |
| `--capacity` | `OSTRA_RUNNER_CAPACITY` | (none: the slots' default) | How many tasks a host runner runs at once: the older name of OSTRA_RUNNER_SLOTS, which wins. |
| `--labels` | `OSTRA_RUNNER_LABELS` | (none) | Comma-separated labels that tasks can ask for, such as gpu,macos. |
| `--name` | `OSTRA_RUNNER_NAME` | the machine's host name | The runner's name in the panel. |
| `--join-token` | `OSTRA_JOIN_TOKEN` | (none) | A pool runner's join token, used once to register. A personal runner signs in with a device code instead. |
| `--shell` | `OSTRA_RUNNER_SHELL` | bash | The shell the host executor runs setup scripts with. On Linux and macOS, bash from PATH. On Windows, the bare name bash means Git for Windows' own bin\bash.exe, found from the git on PATH, never WSL's System32\bash.exe; without Git for Windows, set it to a shell's full path. A full path is used as given. |
| `--join-token-file` | `OSTRA_JOIN_TOKEN_FILE` | (none) | A file holding a pool runner's join token, such as the bootstrap token core writes at first start. --join-token wins. |
| `--box-base-image` | `OSTRA_BOX_BASE_IMAGE` | ostra/base:&lt;the runner's version&gt; | The docker executor's base image, for an environment that names none. |
| `--box-runner-image` | `OSTRA_BOX_RUNNER_IMAGE` | ostra/runner:&lt;the runner's version&gt; | The image each docker box's sidecar runs: the ostra CLI. |
| `--box-server-url` | `OSTRA_BOX_SERVER_URL` | the --server address | Core's address as a docker box's sidecar reaches it, when that differs from --server. |
| `--slots` | `OSTRA_RUNNER_SLOTS` | docker: the host's CPUs / 2; kubernetes: 20; host: 2 | How many tasks or boxes the runner holds at once (ADR 0059). The server may hold a personal runner to fewer (its member's setting, 2 by default). |
| `--reserve-cpu-millis` | `OSTRA_RUNNER_RESERVE_CPU_MILLIS` | 1000 | The CPU, in millicores, a docker runner keeps for the host and itself: it offers the engine's CPU less this. |
| `--reserve-memory-mib` | `OSTRA_RUNNER_RESERVE_MEMORY_MIB` | 2048 | The memory, in MiB, a docker runner keeps for the host and itself: it offers the engine's memory less this. |
| `--ws-retry-minutes` | `OSTRA_RUNNER_WS_RETRY_MINUTES` | 10 | After falling back to HTTP, how often the runner tries the WebSocket again. |
| `--pin` | `OSTRA_RUNNER_PIN` | true | Whether a runner installed from npm installs its server's version at start (ADR 0034). false keeps the installed one, inside the version window. |
| `--npm-registry` | `OSTRA_RUNNER_NPM_REGISTRY` | https://registry.npmjs.org | The npm registry the pin installs the ostra CLI from, such as a company mirror. |
| `--host-pool-agent-user` | `OSTRA_HOST_POOL_AGENT_USER` | (none: a host pool runner refuses to start without it) | The OS user a host pool runner runs the agent as, separate from the runner's own (Linux and macOS). |
| `--k8s-namespace` | `OSTRA_K8S_NAMESPACE` | the service account's namespace | The namespace a kubernetes runner makes its boxes' pods in. The cluster must run Kubernetes 1.29 or later, for native sidecars. |
| `--k8s-build-namespace` | `OSTRA_K8S_BUILD_NAMESPACE` | &lt;namespace&gt;-builds | The namespace a kubernetes runner builds snapshots in, with BuildKit. |
| `--k8s-node-wait-minutes` | `OSTRA_K8S_NODE_WAIT_MINUTES` | 15 | How long a kubernetes box waits for a node before it fails and its task is queued again. |
| `--k8s-runtime-class` | `OSTRA_K8S_RUNTIME_CLASS` | (none) | The RuntimeClass a kubernetes box's pod runs with, such as gvisor. |
| `--egress-allow` | `OSTRA_EGRESS_ALLOW` | the server's address only | Comma-separated addresses a docker or kubernetes box may reach in private ranges, besides the server's (F-116). |
| `--sidecar-cpu-millis` | `OSTRA_SIDECAR_CPU_MILLIS` | 1000 | The CPU limit, in millicores, of a box's sidecar, counted in the box's footprint. |
| `--sidecar-memory-mib` | `OSTRA_SIDECAR_MEMORY_MIB` | 256 | The memory limit, in MiB, of a box's sidecar, counted in the box's footprint. |
| `--service-cpu-millis` | `OSTRA_SERVICE_CPU_MILLIS` | 1000 | The CPU limit, in millicores, of a service that names none, counted in the box's footprint. |
| `--service-memory-mib` | `OSTRA_SERVICE_MEMORY_MIB` | 1024 | The memory limit, in MiB, of a service that names none, counted in the box's footprint. |

## Other flags

| Flag | What it does |
|---|---|
| `--verbose` | Print debug lines too |
| `--help`, `-h` | Print the commands and flags |
| `--version` | Print the CLI's version |

The same runner settings are in the [configuration reference](/docs/reference/configuration), under "The runner".
