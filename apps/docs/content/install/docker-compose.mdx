---
title: "Install with Docker Compose"
description: "From a Linux machine with Docker to the panel's sign-in page, in about ten minutes."
summary: "One compose file brings up the server, Postgres and a pool runner."
---

## 1. Get the compose file

Download this release's compose file into an empty folder.

```sh run
mkdir ostra && cd ostra
curl -fsSLO https://github.com/JoeyKhd/ostra/releases/latest/download/compose.yaml
```

## 2. Start it

```sh run
docker compose up -d
docker compose ps
```

> [!NOTE]
> The first start creates the admin `demo@demo.com` with the password `demo`. The panel asks for a new password at the first sign-in.

> [!WARNING]
> The pool runner mounts the Docker socket, which is root on this machine. Run pools on machines that do nothing else.

## 3. Open the panel

Open `http://localhost:3000` and sign in as `demo`.

> [!CAUTION]
> A runner on the host executor runs agents in a worktree on its own machine. Its agent can reach whatever that account can.

## Required settings

None. Every setting has a working default, listed in the [configuration reference](/docs/reference/configuration). The compose file's runner reads the bootstrap join token from the server's data folder, so the pool runner registers on its own.
