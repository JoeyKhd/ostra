=== 4. The limit that core.longpaths does not lift ===
git itself refuses a git directory path of about 250 characters or more ("fatal: '$GIT_DIR' too big", seen at a 210-character data folder).
So the runner's data folder still has to be short enough for <data folder>\tasks\<task id>\workspace\<checkout>\.git to stay under that;
core.longpaths lifts the limit for everything below it: the files of a checkout, and the refs and locks inside .git.
