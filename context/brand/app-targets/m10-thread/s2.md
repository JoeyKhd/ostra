## Every state of the end of a turn

| State | What shows |
|---|---|
| Checks passed, pushed, PR opened (`s2`) | the push line, then the card with the live CI line |
| A check failed in the box | `Pushed {branch} · 1 of 3 checks failed in the box, so the PR is a draft` (red on `failed`); the card's icon `git-pull-request-draft` `--muted`; the Checks tab's red marker |
| CI passed | the card's line `CI on GitHub passed · 4 jobs`, the tab's green check, the status `In review · AI review` then `· waiting for a reviewer` (milestone 6) |
| CI failed | `CI on GitHub failed: e2e` (red on `failed`); milestone 6's CI round follows as an outlined bubble from ostra (`states-messages.webp`, 1) |
| No CI | `No CI on GitHub` `--faint`, after milestone 6's 2 minutes |
| A later push to the open PR | only the push line: `Pushed 4be21c0 · CI passed` once CI says; no second card |
| No turn running, box idle | the status line's `box idle, stops in {n} min`; the panel's `Box` row |
| The box stopped or was released | `box stopped` / `box released` in the status line; the composer reopens (milestone 2) |
| Hover or focus on any turn's time | that turn's tooltip; on a phone, the opened run's footer instead (`s6.md`) |

## Data it reads

- **The push line:** `data-pushed` (`branch`, `headSha`), the turn's checks (`check.started` / `check.finished`, milestone 3), the PR's draft state.
- **The card:** `data-pr` (`number`, `title`, `url`), the PR's size (`tasks.get` → `repo.pr`, the diff's stat), the latest `CiRun` for the head (`state`, jobs done and total), the project's AI review switch.
- **The tooltip:** the turn's `meta.at`, `meta.endedAt`, `meta.effort`, `meta.usage` (in, out, reasoning, `estimated`), the turn's spend (content fix 4) and its `session.saved` (content fix 2).
- **Turn ordinals** (`Turn 4`): the count of the task's assistant turns up to this one.
