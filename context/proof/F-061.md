## Notes

- **Row 1 is partial.** What's proved is the token endpoint across one minor either way: a runner before minor 2, which sends no `x-ostra-minor` on its token request, gets minor 1's strict error body and its token; a minor-2 runner against a server at minor 1 hears no reason and retries a 401 instead of exiting; and a 403 from that server is still read as revoked. The window at `hello`, with the fix in its message, is tested in `apps/core/src/gateway/gateway.test.ts` ("connects runners one minor behind and one ahead, and refuses two ahead with the fix") and `packages/protocol/src/runner/minor-2.test.ts`; the first doesn't name F-061 yet, and neither has a break-it here. Milestone 5's compatibility matrix of runner N-1, N and N+1 against server N (ADR 0034) is what proves the whole sentence.

Notes (2026-11-19, milestone 5's ticket 06): the fake npm registry (`packages/adapter-sdk/src/testing/net/fake-npm-registry.ts`) serves a stand-in CLI at two versions with their integrity, for the pin (ticket 19); it proves no row by itself.
