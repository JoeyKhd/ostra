## Notes

- The chain, link by link, on real code: the panel's Stop (the e2e, on the production build and an embedded Postgres) and `tasks.stop` queue a `stop` command for the runner holding the lease; the runner's task host (the real host executor, the scripted fake ACP agent as a child process, the real git proxy and a git upstream) cancels the turn, commits what is there, pushes the branch and the hidden ref, acks `done` and releases the workspace; core's stop reaction ends the session `stopped`, frees the lease and opens no PR. The live demo ran the whole chain with OpenCode against GitHub: "Stop ended the turn" and "Stop kept the work" in `demo.md`.
- "Ready to reopen": the branch and `refs/ostra/wip/<taskId>` exist upstream with the work after the workspace is gone, and core records the repo as `branch_pushed` with its head SHA. Reopening itself is F-033's and F-096's proof.
- The e2e runs at desktop width only (`@desktop-only`, which the phone project's `grepInvert` leaves out): it seeds its task once.
