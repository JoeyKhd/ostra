2026-11-19, ticket 50: the reopen row is proved. A fresh box clones the branch as it is; a kept `host` box (ADR 0039's `resumed`, the only executor that keeps one) now takes the branch's new commits before the agent starts. The demo found the gap live: the forced push after a resumed turn had rewound a member's pushed commit (`step09-branch-activity.txt`, `force_push db0e208 -> 77ed0aa`); after the fix (`761a908`) the member's commits stay and the agent read the hand-made commit's file.

Review fix (milestone 3, packages/api): a CLI session belongs to the one member it was made for. `branches` reads only that member's organization and projects (ADR 0051), not every organization the account is in; the device grant records the organization the approver was signed into (`deviceCode.organizationId`, set by an after hook on `/device/approve`), and the poll binds the session, and its `cli-session.started` audit entry, to that organization's member.
