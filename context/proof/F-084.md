## Notes

- 2026-11-19, ticket 28 (m3): rows 1 and 3 are `partial`. Core keeps each turn's four token kinds, spend, agent time and estimated mark as `usage.recorded` and the turn's end arrive, and `readTaskUsage` gives a task's totals and its turns in one query (the totals equal the sum of the task's events across sessions, and another organization's task reads as nothing). The task page that shows them with "≈" is ticket 43, and the API that serves them is ticket 39; each adds its proof. Counting at the key proxy for every call is F-089's. A model with no price shows its tokens and no spend.
- 2026-11-20, OpenCode's subagents (`context/research/opencode-subagents.md`): a subagent runs in the same OpenCode process and calls the model through the task's one provider, the key proxy, so each of its calls is counted like the main agent's, also after the main agent's turn has ended; OpenCode's own turn figures (the prompt's `usage`, `usage_update`'s `cost`) leave a subagent's calls out, and ostra doesn't read them for spend.
