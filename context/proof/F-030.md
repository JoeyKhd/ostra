## Bug fixed while proving it

- **A task's first PR never linked the ones opened after it.** Each PR's footer listed the task's PRs opened before it, so with two changed repos the first PR named no other. The App now sets that PR's body again once every PR exists, through a new optional code host operation, `updatePullRequestBody` (`packages/adapter-sdk/src/code-host/base.ts`; GitHub's `PATCH /repos/{owner}/{repo}/pulls/{number}`, with a token narrowed to `pull_requests: write` and `metadata: read`). Only the PRs that run opened are changed, so no one's edit is overwritten. A code host without the operation answers `unsupported`, and its PRs keep the earlier links only.
