## Notes

- **The check** (ticket 20) is a Vitest test, so `pnpm test` runs it and `ci.yml` is unchanged. It reads `apps/web/src/**/*.tsx` and `packages/task-view/src/**/*.tsx` with the TypeScript compiler API (`src/lib/messages-check.ts`) and fails on JSX text with a letter in it, and on a string literal shown as an `aria-label`, `title`, `placeholder`, `alt` or a toast's message, outside `t`, through branches, fallbacks and templates. `messages/allowed-literals.json` lets through the names that aren't words (the product's name, a keyboard key, a setting, a path, a command, an example of a field's format), each with its reason, and the third test fails on an entry no source still has. Every key of `en.json` must be named by a source, as a literal or by a template that spells its start (`` `budgetWait.${scope}` ``).
- **Refusals are codes:** `errorText` words a FORBIDDEN (a role refusal) and a NOT_FOUND through `t`, never the server's English; a budget stop reaches the task page as `stopReason`/`limit` codes and is worded in its limit block. The `model-format` refusal the ticket names was Claude Code's format check, postponed with F-018 (2026-11-19), so there is none to seed.
- **The pseudo-locale:** `OSTRA_PSEUDO_LOCALE=1` at `next build` (it builds into `.next-pseudo`) and `next start` makes `t` wrap every message as `⟦…⟧` with its letters accented (`src/lib/pseudo-locale.ts`). `e2e/pseudo-locale.spec.ts`, on its own stack (`playwright.pseudo.config.ts`), walks every route of `e2e/routes.ts` signed in and signed out, plus an approval's and a question's task page, and finds every visible text node outside the brackets. It leaves out the seed's user data (marked in `seed-routes-world.ts`: titles, names, keys, a note's text, the install's pools and box sizes), the allowed names, the month and weekday names `Intl` writes from the locale, and what the panel sets as machine values (`code`, `kbd`, `pre`, `.font-mono`, `translate="no"`). The proof workflow's `e2e` job runs it after the main suite (never `ci.yml`).
- **Run it by hand:** `OSTRA_PSEUDO_LOCALE=1 pnpm --filter @ostra/web exec next build`, then `OSTRA_PSEUDO_LOCALE=1 pnpm --filter @ostra/web exec playwright test -c playwright.pseudo.config.ts`. Its stack takes the ports twenty above `OSTRA_E2E_PORT`.
